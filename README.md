# CareerPilot

AI-powered career guidance platform for students and fresh graduates.

## Features

* ATS-friendly Resume Builder
* Resume PDF Download
* ATS Score Analysis
* Career Recommendation Engine
* Personalized Learning Roadmaps
* Interview Practice Quiz
* AI Interview Feedback
* Resume History Dashboard

## Tech Stack

### Frontend

* React
* Vite
* React Router
* CSS

### Backend

* Flask
* SQLite

### AI Integration

* OpenRouter API (Llama model)

## Run Locally

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
pip install -r requirements.txt
python app.py
```
